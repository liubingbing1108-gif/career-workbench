# 情况决策表

`semantic_status` 只表示问题和字段的关系；`availability.status` 是程序检查答案后给出的证据，二者不可互相替代。以下均为候选，不是执行指令。

| 情况 | semantic_status / plan.kind | 可用性及后续 | 不允许 |
|---|---|---|---|
| 同对象同口径的多个同义叫法 | equivalent / alias | ready 或 not_evaluated；多个问题各指向同一个现有 ID | 因名字不同创建定义 |
| 已有字段无值 | equivalent / alias | missing_value；补当前对象的值 | 改成 new 或从另一对象补值 |
| 已有字段，无合适字数/语言/公司版本 | equivalent / alias | version_needed；原文保留，后续准备待确认草稿 | 截断、自动另存、跨公司套用 |
| 同一事实需年月/年份等格式 | transform / transform | 程序核验精度、类型、实际选项，转换后重新验长 | 月份补日、考试成绩推能力 |
| 一个问题问职责和成果 | compose / compose | 列出所有来源及对应部分；缺项仍显式保留 | 把整题登记成某一个字段的别名 |
| 从完整描述分出职责/成果 | extract_candidate / extract | 只提已授权来源片段引用与 Unicode 字符区间；draft_required | 推断未明示职责、把摘取直接存共享值 |
| 只覆盖题目一部分 | ambiguous / none | coverage.partial=true，uncovered 非空；保留已知来源与候选，相关项待确认 | 标全匹配或隐藏剩余问题 |
| 多个候选、范围或尺度不清 | ambiguous / none | alternatives 与理由；not_evaluated 或 conflict | 以高置信度、使用次数、排序选第一条 |
| 目录排查后确实是新属性 | new_attribute_candidate / none | 名称、含义、对象、类型、单位及排查回执；not_evaluated | 正式 ID、共享作用域和写入指令 |
| 问题不完整、未知对象、检索不全 | unresolved / none | 指明缺失内容；必要时 request_expand_catalog=true | 用 new 兜底 |
| 模型失败、坏 JSON、过期修订 | 程序错误，不伪造正常候选 | 保留确定关系和草稿，仅未知/受影响项失败 | 整页清空、无限自动重试或旧提示词静默回退 |

同一 category 不代表同一对象或子类型：`language/ability` 与 `language/exam` 分开；多个考试分项必须取同一次。家庭成员具备用途事实才能成为紧急联系人。教育最高学历筛选须区分在读和已取得，毕业日期不能证明已毕业或取得学位。

选择按当前要求处理：教育范围自动成组；实习组合与顺序按用户本次决定；其他未限条数的重复对象取全部适用已确认项。代表性或明确数量限制才要求取舍；不能因为多条记录或多版本就让用户逐条选。完整字段组版本共同切换表达，客观事实共用；已有适用默认版可复用，不能覆盖本次明确选择。

日期/数值的格式方案与语义字段关系分别保存。问题说明、选项、单位、尺度或对象范围改变须重验关系；仅字数变化保留字段对应，重新核验各字段长度与版本适用性。字/词/字节口径未知则不得报告精确达标。

只有任职和项目的已定表达字段保留长期版本，事实按对象共用；无默认允许为空，删除或恢复不自动改选。能力与考试同一网页行可分别建立来源选择，不混类别/子类型；语种必须一致，考试各值属于同一次当前结果。四档自评按选项含义对应，无法明确时交本次草稿确认，不生成新的综合评价预设。
