## 已有链路

实际项目为本工作台。未读取活动数据库或真实文件，未重启服务、修改模型配置或向模型发送资料。

1. 产品异步上传先保存原件与任务；MarkItDown本机转换，保存完整Markdown块和最多16000字符的展示预览。
2. CodexRecognizer使用当前字段目录及文档正文，要求结构化对象、原文引用、完整描述、语言与考试分组。
3. grounded_candidates核验分类、值格式、引用与正文中的文本；生成候选。
4. reconcile_semantic_imports按身份键及字段值生成一致、合并、新增、描述待检查、事实冲突或归属待确认结果。
5. 现有预览及identity/resolve接口接收人工决定；组内待处理项一起保存或忽略，修订检查及事务保护写入。

## 当前缺口

| 观察 | 证据与影响 | Skill及程序各自承担什么 |
|---|---|---|
| Skill没有自动接入识别器 | recognizer.py:123明确关闭skills.include_instructions，另禁用skill_search；只安装目录不会改变产品请求 | Skill维护解析语义；后续适配器显式纳入审核后的相关规则，不开启所有个人Skill |
| 来源只到全文 | document_markdown.py返回一个“Markdown全文”块；核验检查value是否在所引块中，不要求值在quote或所属对象范围内 | Skill要求对象范围；程序验证范围、摘录、值及对象绑定 |
| 完整性缺少独立检查 | 连续短摘录也满足子串检查；有“完整保留”提示但没有覆盖核对 | Skill要求完整描述及遗漏清单；程序维护原文范围和覆盖检查，不用提示词代替断言 |
| 身份键在不同对象上偏松或偏紧 | 项目/活动按名称，实习按公司+角色+起止时间；缺锚点退回导入内身份；归属复核分支主要覆盖已入库实习结束时间差异及缺日期奖项 | Skill输出归属证据和歧义；程序保存用户关联决定、执行去重与修订控制 |
| 语言边界主要靠模型遵守 | 输出entry无record_type；旧词表仍有“语言／考试”；新目录已有ability/exam，但导入并未完整表达该类型 | 候选明确区分能力/考试；具体如何承载需与现有契约适配，不能本轮定新schema |
| 长描述里的事实变化未细分 | lab.py对已有versioned_text差异统一给“描述待检查”，未单独标出数字/职责范围事实冲突 | Skill区分表述与事实差异；程序保存确认与拒绝未解决事实变更 |
| 字段同义缺少确定性兜底 | 提示鼓励复用词表；grounded_candidates的新字段回收主要按同分类同label，不独立校验全部别名语义 | Skill按含义与对象对应；程序校验ID和归属，歧义交回预览 |

这些是局部实现边界，不表示真实资料已经出现相应错误。没有执行真实资料审计或真实模型准确率评估。

## 本轮纯内存复现

只导入现有Python函数，构造虚构文本，不建数据库、不调用CLI或MarkItDown、不读运行资料。

输入全文：

```text
甲示例公司 产品实习 2024.01—2024.03
整理需求清单。
完成12次访谈。
乙示例公司 数据实习 2025.04—2025.08
```

模拟模型把甲公司的开始日期返回为2025-04，引用甲公司那一行；经历描述只返回“整理需求清单。”。grounded_candidates实际接受两项，rejected为空。证明现有核验能放过跨对象日期和截短描述；不证明真实模型必定犯错。

另调用identity_key：两个“示例平台”项目即使起始年份分别2023/2025，键相同；缺日期的“示例语言考试/520分”身份键为空。这分别说明名称键不足以区分事件、缺日期无法直接跨文件自动归并；不直接断言最终已误写资料库。

## 接入设计的后续位置

具体接入流程已单列到 [流程与接入设计](integration.md)：现有识别器显式加载受控解析规则，沿用原任务、预览和资料库；不开放全部个人Skill，也不增加独立Agent流程。该方案尚未实施。

模型承担对象理解、同义映射和事实差异解释；程序承担原文位置、合法引用、覆盖核验、稳定ID、增量一致性、修订、事务及回读。模型网络连接失败和长请求超时继续由现有调用层诊断，Skill不承诺解决服务稳定性。

输入/输出目前仅提出语义要求，不锁定五层界面、字段数或新存储格式。用户已确认的资料组版本规则必须落实到导入适配，不能继续按旧字段级保存解释。最新补充要求同一信息的不同表述（包括获奖简称/详细版）由用户选择保留某版或多版；不能受旧五类模块限制，也不能被语义去重吞掉。接口和存储需支持同一记录关联多个可用表述，不能仅靠保留原附件冒充版本功能。接入需对齐主产品届时有效契约；本轮仅修订草案，没有修改共享产品或真实资料。

同公司同岗位但结束月份不同的关联规则，以及缺日期奖项先核对已有资料的规则，均已确认，不再作为讨论问题。真正待用户决定的行为见 [待决定事项](open-decisions.md)。
