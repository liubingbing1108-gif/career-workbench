# v0.2.0 开源预览版

2026-10-15，采用[MIT许可证](../LICENSE)。插件包1.3.9、核心1.2.36、客户端1.2.13，协议v1。

本版包含完整资料组编辑与版本、指定表单链接、部分填写、停止重试、官网进度只读查询、投递确认与时间线、搜索候选/多选/年月/附件解析顺序修复。新增跨系统安装器和只读诊断，补齐MarkItDown开发依赖。

源码采用白名单导出并保留现有公开前审核的Git历史。排除运行库、原简历、截图、凭据、个人申请链接、历史聊天及现场报告；SOURCE_MANIFEST.json列出源码包文件。发布前检查当前树及全部可达历史，CI只用虚构资料和临时空库。

Release提供完整源码包、独立Chrome扩展包及SHA256校验文件。普通用户需Python3.11+和Chrome，模型语义能力需自行配置已登录兼容Codex或JSON Agent。开发锁要求Python3.12+、Node22+。不包含浏览器、模型账号或凭据。

验证状态以本版本GitHub Actions为准；安装矩阵覆盖Windows/macOS/Linux的空库与双模块启动，完整离线和虚构Chromium界面在Linux执行。真实官网兼容只覆盖有限样本，仍有不支持的动态分支。没有草稿入口的官网请保留现场，最终提交由本人完成。
