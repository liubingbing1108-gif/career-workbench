# v0.3.0 开源预览版

2026-10-22，采用[MIT许可证](../LICENSE)。插件包1.3.9、核心1.2.36、客户端1.2.13，协议v1。

本版新增简历解析 Skill、转换文本清理与原件复核、统一疑点表单、分组确认与版本保存保护，并发布项目治理与自动接续检查。完整更新与未实施的资料管理重构边界见[变更记录](../CHANGELOG.md)。不重新处理已有已确认资料；执行器协议与扩展版本不变。

源码采用白名单导出并保留现有公开前审核的Git历史。排除运行库、原简历、截图、凭据、个人申请链接、历史聊天及现场报告；SOURCE_MANIFEST.json列出源码包文件。发布前检查当前树及全部可达历史，CI只用虚构资料和临时空库。

Release提供完整源码包、独立Chrome扩展包及SHA256校验文件。普通用户需Python3.11+和Chrome，模型语义能力需自行配置已登录兼容Codex或JSON Agent。开发锁要求Python3.12+、Node22+。不包含浏览器、模型账号或凭据。

验证状态以本版本GitHub Actions为准；安装矩阵覆盖Windows/macOS/Linux的空库与双模块启动，完整离线和虚构Chromium界面在Linux执行。真实官网兼容只覆盖有限样本，仍有不支持的动态分支。没有草稿入口的官网请保留现场，最终提交由本人完成。

第三方依赖按各自许可证分发，见[说明](../THIRD_PARTY_NOTICES.md)。


## 此后每次更新

按[治理规则](../GOVERNANCE.md)从独立变更片段汇总发布记录，检查版本、兼容/迁移、安装、接口、隐私及确切提交CI。`python scripts/check_project.py --notes`只生成待发布摘要；它不自动打tag、上传或修改数据。历史Release和tag不可覆盖。GitHub远端main规则须维护者配置并回读，仓库内CI不等于已强制保护。
