# 验证范围

运行 `python scripts/run_tests.py` 执行 Python 及 Node 离线回归，`--ui` 加跑临时本机页面的 Chromium 界面测试。安装方式见 README。默认不访问招聘官网、不调用模型、不读取真实资料库。

测试覆盖字段与来源核验、增量／版本、教育完整集合、实习选择和顺序、岗位隔离、删除事务、官网证据／岗位匹配、重复进入、保存队列、执行锁、未知字段拒绝、人工变化保护、原件上传等待、暂存后内容丢失和进度报告。

发布测试具体结果在 [发布记录](RELEASE.md)。离线适配器和 DOM 夹具证明程序约束，不能证明当前所有真实官网接受。浏览器测试是虚构页面，没有最终申请提交。

`test_live_requirement_mapping.py` 和 `test_semantic_browser.cjs` 是显式手动运行的真实模型实验；默认测试入口不执行其 run 方法，不在 CI 中运行。仅使用虚构材料，仍会产生模型费用，需要自行配置和授权。

实际网站测试必须逐次明确网站、本人材料和允许动作，保留失败和未支持项。区分本轮新写入、原有相同值、当前回读、保存回应、重开持久核对以及最终本人提交。历史有限平台验证不等于任意整表 60 秒或语义准确率承诺。


直接申请页优先核对指定页面的公共公司、租户与具体岗位；资讯/首页先选具体岗位。用户明确指定的HTTPS表单按要求解析，身份/标题差异提示，原来源、人工状态和日期保留。已登录动态页无静态正文不等同需重新登录，也不直接启动漫长全网查找。执行始终绑定本人指定或已核验的本岗位目标。

插件独立只读复核模式不填写、上传、新增记录或暂存。异步搜索页壳不视为表单已加载。实际无草稿且重开丢失时，恢复已确认材料后保留当前页并提示本人提交，不称保存成功。当前包1.3.9/核心1.2.36/客户端1.2.13，协议v1，权限不变。有限真实平台验证不能代表任意网站、隐藏表单或跨系统均已验收。


接续修复：只读复核需要实际资料字段，搜索/验证码框不能单独证明表单已加载。核验成功不会误报尚有内容未完成或正在保存；新的填写确认先重新连接填写模式。相关回归使用虚构资料；有限真实验证不代表所有招聘系统通过。

v0.2.0 发布前在全新源码导出和全新虚拟环境中验证：370 项 Python 测试（资料 269、管理 97、安装诊断 4），111 项 Node 测试，以及全部 13 个界面测试脚本通过。空库初始化、双模块随机端口启动、依赖完整性与 61 个文档相对链接检查通过。测试未调用真实模型或招聘官网。

GitHub Actions 另外提供 Windows、macOS、Linux × Python 3.11/3.14 安装和启动检查，并在 Linux/Python 3.12 执行完整离线与 Chromium 回归；最新实际状态见仓库 Actions，不能用离线检查替代真实网站兼容性验证。
