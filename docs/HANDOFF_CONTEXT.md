## 接续顺序

读 [协作规则](../AGENTS.md)、[产品规则](PRODUCT_REQUIREMENTS.md)、[Agent 接入](AGENT_INTEGRATION.md)。在隔离空库复现问题，修改现有模块，跑对应回归和完整离线测试。用户数据不属于测试夹具。

优先事项是复杂控件／动态分支适配与真实网站保存可靠性、Windows/Linux 的完整用户安装、长期断连恢复和官网进度查询。细项见 [路线](ROADMAP.md)。不能重新引入飞书日常同步、独立工作台主 Tab、机会池、自动提交或人工日期自动生成。

需区分源码版本、浏览器已加载版本、离线测试、真实网站接受和本人提交。自选 Agent 已有可运行协议，但每种外部 Agent 的模型质量、搜索回执和权限限制需要集成者验证。

发布复核补充：Linux首次CI暴露附件选择保存期间可过早点击成组补充保存。现已让分组保存按钮随队列和本组请求禁用／恢复，并用受控延迟响应验证；不以加长超时或跳过断言掩盖问题。

录入修复：明确的公司＋具体岗位＋链接直接预览，不等待网页或模型；无正文或识别失败保留原链接供补充。多链接分别对应来源，括号/空白等价时保留原文。录入仍需用户选择，官网核验及材料确认独立执行。


直接申请页优先核对指定页面的公共公司、租户与具体岗位；资讯/首页先选具体岗位。身份/标题冲突须明确处理，原来源、人工状态和日期保留。已登录动态页无静态正文不等同需重新登录，也不直接启动漫长全网查找。未闭环禁止执行。

插件独立只读复核模式不填写、上传、新增记录或暂存。异步搜索页壳不视为表单已加载。实际无草稿且重开丢失时，恢复已确认材料后保留当前页并提示本人提交，不称保存成功。当前包1.3.3/核心1.2.21/客户端1.2.10，协议v1，权限不变。有限真实平台验证不能代表任意网站、隐藏表单或跨系统均已验收。


接续修复：只读复核需要实际资料字段，搜索/验证码框不能单独证明表单已加载。核验成功不会误报尚有内容未完成或正在保存；新的填写确认先重新连接填写模式。相关回归使用虚构资料；有限真实验证不代表所有招聘系统通过。
