## 接续顺序

读 [协作规则](../AGENTS.md)、[产品规则](PRODUCT_REQUIREMENTS.md)、[Agent 接入](AGENT_INTEGRATION.md)。在隔离空库复现问题，修改现有模块，跑对应回归和完整离线测试。用户数据不属于测试夹具。

优先事项是复杂控件／动态分支适配与真实网站保存可靠性、Windows/Linux 的完整用户安装、长期断连恢复和官网进度查询。细项见 [路线](ROADMAP.md)。不能重新引入飞书日常同步、独立工作台主 Tab、机会池、自动提交或人工日期自动生成。

需区分源码版本、浏览器已加载版本、离线测试、真实网站接受和本人提交。自选 Agent 已有可运行协议，但每种外部 Agent 的模型质量、搜索回执和权限限制需要集成者验证。
