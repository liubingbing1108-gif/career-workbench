# 开发交接

v0.2.0，2026-10-15，MIT开源预览。插件包1.3.9、核心1.2.36、客户端1.2.13，协议v1。仅源码与虚构测试分发，历史私人资料和现场记录不公开。

## 当前行为

- 两个主入口：我的资料、投递管理；每岗独立材料预览与执行。
- 资料按模块、记录、完整资料组版本管理；本次修改默认仅供本岗位。缺项留空，不阻塞独立已确认项；删除只影响明确选择的范围。
- 手动表单链接入口；按本人指定页面解析，身份差异提示。官网进度查询为只读，唯一明确记录才更新招聘阶段。
- 停止后可重试；跳过一致值、保护已有不同值。Sugar支持搜索候选、全称添加、多选与年月；字段同名按类型和所属分区定位。
- 自动解析附件先上传，随后填材料；当前回读、附件回执、官网保存、最终提交分别报告。无草稿入口不刷新，最终提交由本人完成。
- 已确认投递按钮由用户点击后同步状态和日期；自动填写不会标记已投递。

## 安装与维护

新用户用bootstrap.py；doctor.py只做本机只读检查；smoke_install.py用临时空库与随机端口验证双模块。运行依赖Python3.11+，完整开发锁Python3.12+。CI的安装矩阵不代表各操作系统所有真实官网已通过。

阅读[协作规则](../AGENTS.md)、[产品规则](PRODUCT_REQUIREMENTS.md)、[Agent接口](AGENT_INTEGRATION.md)、[安全边界](../SECURITY.md)。测试默认使用虚构资料和临时数据库；真实模型或官网需要用户明确授权。

已知限制：复杂联动、iframe及网站更新可能中断；附件解析后的异步表单重建可能需要重新确认/重试；缺失事实与协议由本人补充。详见[测试](TESTING.md)和[路线](ROADMAP.md)。不得将有限样本的字段一致率写成任意网站成功率。
