# Resume Skill integration

The recognizer explicitly loads `skills/resume-material-parser/SKILL.md`, versions the rules, and validates source ranges, field/object types and full descriptions. Imports offer keep existing, keep incoming, or retain complete alternatives under one record, including awards. Facts require separate conflict confirmation; ignores apply only to the current import.

Validation on 2026-10-22: the unified test command passed 433 Python tests (308 profile, 97 management, 28 engineering), 111 Node tests and all 15 isolated browser scripts. Resume tests cover identity confirmation, A/B preview, complete alternatives, reload, version switching and preservation of originals/defaults. Clarification tests cover optional dates, explicit meaning confirmation, notes, stale revisions and atomic saves. No real data is bundled; these are local results, not a claim that remote CI has run.

Converted text is cleaned conservatively while retaining raw text. Layout doubts trigger review of original PDF layout text/page images or Word XML structure and available local page rendering. Explanations of abbreviations remain suggestions until accepted. All prompts are collected in an optional clarification form; completing it updates candidates, not shared facts. Missing dates may remain empty. An unresolved source-attribution question remains pending after skipping; only its affected object is blocked. Other objects may be saved, and unsaved questions can be reopened later. Saved answers are locked, and source confirmation cannot bypass independent grounding failures. The audit found and repaired a previous gap in this skip path.

Storage compatibility: no new database or bulk rewrite of confirmed imports. New imports carry a parser contract and retain whole-group references in the existing version service; old confirmed imports remain under their historical contract. Ordinary saves do not add versions. Startup does not normalize existing empty records solely to add metadata.

Limitations: model connections and complex PDF reading order can fail. Original-page review is bounded to the first eight pages; Word visual review requires a local renderer, otherwise only structure is available. Rejected evidence and ambiguous identities remain explicit; Markdown agreement does not prove the original document was converted perfectly. Never interpret these tests as universal resume accuracy or recruiting-site acceptance. This document describes the implemented import contract; later category-specific version restrictions are separate pending product work and are not established by the legacy award-alternatives test.
