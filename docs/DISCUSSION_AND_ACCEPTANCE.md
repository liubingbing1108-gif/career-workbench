# 验收标准

本页列出应持续维持的验收目标，不代表每种网站都已通过。结果见 [测试](TESTING.md)，未完成见 [路线](ROADMAP.md)。

| 领域 | 必须满足 |
|---|---|
| 入口 | 资料／管理两个核心入口，工作台二级承接；返回重入有响应，不被旧请求覆盖 |
| 录入 | 候选预览与本人选择；仅投递意图；重复独立录入正常新增 |
| 官网 | 来源永久保留，官方入口另存；实际证据和准确岗位核验前不启动填写 |
| 管理 | 人工已投、独立招聘进度、人工日期；失败不猜阶段，删除保留共享资料 |
| 全表单 | 无简历也能维护，字段可扩展；增量一致项复用、冲突可暂缓 |
| 记录 | 完整教育集合按官网范围，实习组合／顺序／每段版本，关联事实不串记录 |
| 版本 | 原地新增，默认稳定；导入替换／新版本／忽略；投递更新／新版本／仅本次 |
| 材料 | 只展示必要决定，右侧预览全部实际值；未保存或歧义未解决不能确认 |
| 附件 | 选择原件，等待真实上传完成，失败可见；不改附件、不假上传 |
| 执行 | 插件优先，同页进度，复用官网页；保护人工修改，未知项不猜填 |
| 保存 | 分别记录填写、回读、暂存回应、重开保留；丢值／附件缺失不能成功 |
| 接手 | 登录／验证码／协议／最终本人提交；完成去官网确认或返回，管理不自动已投 |
| 可复用 | 空库显式初始化不覆盖旧库、自选 Agent 契约、依赖锁、虚构测试、完整文档 |
| 隐私 | 源码白名单导出，个人资料／原件／凭据／历史现场和 Git 历史隔离 |

实时画面、全部平台、跨系统实机、官网个人中心导入与招聘进度查询单独验收；不得将候选功能标成完成。
