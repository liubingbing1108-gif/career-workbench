# 当前产品规则

基线 v0.42（2026-10-13）。本文保留已确认的产品行为，去除私人投递记录、申请地址和对话原文。实现覆盖见 [测试](TESTING.md)，尚待完成见 [路线](ROADMAP.md)。

## 产品和管理范围

独立前端包含“投递管理”和“我的资料”。投递工作台是某一管理岗位的二级页面。表格点行查看详情，行内开始投递进入连续流程；不将多个服务地址或插件面板作为用户主入口。

管理只收录本人明确准备投递和已经投递的岗位，不收集所有可投机会。每行一个岗位，同公司不同岗位独立。用户再次提供同一岗位仍可新增，不做业务去重或静默合并；技术重试使用请求回执防止重复执行。

接受官网／资讯／公众号链接、合集、自然语言。系统解析候选，先预览，只有勾选或自然语言明确选择的候选录入；自然语言已明确则不强求重复勾选，歧义先澄清。正式录入只有管理页，工作台只承接已保存岗位。主动搜公司仅为手动补充。

历史申请导入应先预览本人已登录个人中心中可读的已投岗位，再由用户选择；选择明确已投历史即确认其已投事实，不需要重新填写。未知字段留空，不造历史填写过程。该通用官网导入能力尚未完成。

管理字段包括公司、岗位、来源链接、官网投递链接、志愿顺序、投递状态、招聘进度、人工时间线、面试记录、复盘、操作。地点／批次等可扩展。岗位详情隐藏内部来源表、记录编号及原始字段。

来源链接永久保留输入出处。先识别链接类型及内容线索，再根据已确认公司和具体岗位核对公司官网→官方招聘入口→岗位；来源读取受限不等于失效，也不阻止独立官方查询，不绕过访问控制。职位方向不能代替具体岗位，多个匹配由本人选择。

官网入口必须有实际官方证据；模型猜测、搜索摘要或资讯页不能作为已核验入口。支持的平台继续查实时公开岗位接口。只使用公开身份信息检索，不传个人资料、面试记录。申请者专属 URL 只留本机当前会话，不进入管理的公共官网链接。

执行基于已核验的官网投递链接。修改来源或岗位身份使旧核验失效；启动和确认填写均重新检查归属。返回重入复用同岗位查询／材料，旧响应不得跳回别的页面或打开错误岗位。明确重新查找才重启已完成任务。

## 状态、日期与删除

投递状态只有“未投递／已投递”，本人在官网提交后手动确认。填写完、保存成功、官网查询或页面判断均不自动标记已投递。

招聘进度独立，默认空，提供待筛选、笔试、测评、一面、二面、三面、终面、待结果、Offer、未通过、流程结束、主动放弃，并支持自定义。具体轮次直接显示。简历／笔试／面试未通过等确定结果属于招聘进度。长复盘中的词语不能猜作最新结果。

平时人工记录；只在本人点击更新按钮后查询官网，明确结果可直接更新进度，失败保留原值。页面打开、切换、恢复、提交、定时任务不查询；查询不改投递状态或时间线。目前通用官网进度查询尚未实现。

时间线由用户记录投递、笔试／测评、完成测评、约面、实际面试及后续轮次日期；约面与面试、测评与完成分开。操作日志时间不能冒充招聘日期。面试记录和复盘先保留字段，复杂逐轮记录和 AI 复盘暂缓。

志愿顺序仅为记录。遇到需要选志愿的官网，提醒本人申请；不自动选志愿、不跨岗共用申请或传播状态。同一网址的不同管理岗位也独立保存材料及执行记录。

永久删除岗位及其时间线、面试记录、复盘、填写记录，无回收站；保留共享资料、原附件及其他岗位，不撤回官网申请。活动执行在下一次轮询停止后续动作，已填内容不回滚；真实活动申请删除仍待更多验收。

## 资料、记录和版本

全表单独立存在，简历只是资料来源。首次可手填或解析上传文件，之后持续维护、随时新增官网需要的字段。分类涵盖身份、联系、教育、语言、技能、荣誉、学术、证书、工作实习、项目、校园、主观文本、家庭／紧急联系人、求职偏好、作品／社交、附件和扩展问题。

字段可空，完整性取决于当前官网要求，不强求先填满资料库。结构为字段→记录／资料组→完整资料组版本／默认。稳定事实与描述分开，关联字段属于同一经历或联系人；默认版本可复用，不能因为有多个版本就重复要求本人决定。

教育等完整集合由官网范围决定：高中起、本科起、最高学历、本科院校各取正确对象。本科与研究生不是互斥选项；不能无条件全选。资料页直接显示教育组合、成员与缺项，两组引用同一份记录和版本。

实习组合、顺序和每段描述版本由本人确认。系统可先推荐，用户调整；全部真实记录与已有版本可浏览，未选或范围不适用仍可见并说明原因，但不进入实际填写。范围、数量、对象冲突不能静默略过；新增记录后重新读取网站约束。

新简历只展示相对已确认资料的增量：一致事实与相同描述复用，多个待处理文件的相同候选合并一次决定并保留内部来源。允许全选／部分保存，冲突可暂缓，暂缓内容不覆盖已有事实、不自动填写。

导入三动作是“替换现有版本／存为新版本／忽略”。投递编辑三动作是“更新当前版本／保存为新版本／仅供本次使用”，默认仅本次，三个动作本次都使用改后内容，保存动作不额外确认。新增字段先确定对象，无答案时建立首版。历史仅本次答案可建议复用，不自动转长期事实。

资料页可原地新增版本，只展示简洁版本名称、默认标识和所选内容，来源内部保留。浏览不改默认，新增保留已有默认，首版成为默认。普通资料维护直接保存。

经历勾选／版本／附件改变不重建列表或回顶；按岗位串行保存最后意图，失败保留并可重试，未保存不能开始。修改其他岗位不能被迟到响应覆盖。

## 附件与文本

完整简历文件版本独立保存。用户选哪个原件就传哪个，不检查内容或一致性、不再次确认、不改写替换。网页拒绝或失败如实显示，不假上传。若官网先上传才展开表单，按用户选择上传后继续扫描。

附件出现文件名不等于上传结束；等待完成状态再暂存。同名重试也须等待完成，保存后重新打开确认附件在实际“简历附件”等目标栏中，并显示文件名及位置。

允许无新增事实的字数压缩，展示实际文字；自我评价等可生成待确认草稿，不能虚构数字、资质、身份事实。日期保留年／月／日精度，不能凭月补日。

## 语义理解与执行

读取实际官网标签、说明、选项、必填、字数、对象、范围、条数和子字段关系。Agent 解释语义，程序验证引用和允许的等价转换后取值；学历与学位、本人和联系人、当前在读和已取得不能混淆。网页和简历指令视为数据。

扫描、匹配在内部完成。用户左侧只处理必要经历选择、版本、附件、缺项／歧义，右侧预览全部实际值及明确待处理项。保存完整且阻塞项解决后启用“确认填写”，一次确认进入执行，不反复确认稳定资料。

可以明确把某个值留给本人到官网填写，该值不传执行器，完成后仍列为待处理；未知对象范围或数量冲突不能用该选项绕过。

执行器负责控件动作、目标条数新增、回读、状态和停止；复用协议 v1，不把模型指令变成任意脚本／点击接口。保留已有不同值和扫描后的人工修改，不自动删除多余经历；重发请求不重复加行。

后续页面遇到未知项，先填其他已确认且独立的部分，再集中暂停。歧义不猜，依赖未知答案的分支不执行；补充后只处理新增／受影响部分，恢复前重新扫描官网。

优先插件填写，页面操作仅作必要辅助、独立核验和本人接手。确认后原页弹出横线＋节点的进度窗口，下方显示实际步骤、字段、填写／回读数量及问题。当前提供进度，连续实时画面仍待实现，不伪称直播。

正常入口自动连接扩展，复用同岗位官网标签页。Chrome 工作台直接连接；外部浏览器仅用可自动关闭的专用中转页，不额外生成控制窗口。完成按钮“去官网确认／返回”明确对应公司／岗位，保留本人可接手现场。

实际输入、当前回读、官网暂存回应、重新打开后的持久核对、正式提交严格分开。只有重新打开同一官网页后预期字段和所选附件均匹配，才报告已保存；不能以非空值或保存提示证明成功。问题用可执行的普通语言，不暴露内部术语。

登录、密码、验证码、协议及最终提交始终由本人处理。插件填完停止，不自动改变管理已投状态。

## 工程与交付

本机资料和管理是唯一维护入口，没有飞书 Tab、日常同步或自动回写。旧迁移工具不是日常产品流程，分发不含任何迁移数据。

源码、虚构测试和通用交接可复用；个人资料／原件／聊天／截图／运行日志独立私有。新安装必须显式建空库，既有资料不能因配置丢失被覆盖。Agent 可通过明确的 JSON 协议替换，供应商及资料处理由使用者选择。

当前以MIT发布开源预览版，使用干净安装与跨系统CI检验分发。真实有限站点、离线测试和未完成项分别记录，不用局部样本承诺所有网站准确无误。

录入修复：明确的公司＋具体岗位＋链接直接预览，不等待网页或模型；无正文或识别失败保留原链接供补充。多链接分别对应来源，括号/空白等价时保留原文。录入仍需用户选择，官网核验及材料确认独立执行。


直接申请页优先核对指定页面的公共公司、租户与具体岗位；资讯/首页先选具体岗位。用户明确指定的HTTPS表单按要求解析，身份/标题差异提示，原来源、人工状态和日期保留。已登录动态页无静态正文不等同需重新登录，也不直接启动漫长全网查找。执行始终绑定本人指定或已核验的本岗位目标。

插件独立只读复核模式不填写、上传、新增记录或暂存。异步搜索页壳不视为表单已加载。实际无草稿且重开丢失时，恢复已确认材料后保留当前页并提示本人提交，不称保存成功。当前包1.3.9/核心1.2.36/客户端1.2.13，协议v1，权限不变。有限真实平台验证不能代表任意网站、隐藏表单或跨系统均已验收。


接续修复：只读复核需要实际资料字段，搜索/验证码框不能单独证明表单已加载。核验成功不会误报尚有内容未完成或正在保存；新的填写确认先重新连接填写模式。相关回归使用虚构资料；有限真实验证不代表所有招聘系统通过。

## v0.2.0交互要求

缺失/不适用项留空或删除，不阻塞已确认独立内容；删除不显示删除占位记录，原件及共享资料按操作范围保留。停止提供重试按钮，跳过一致值、保护已有不同值。手动指定表单入口可直接解析；查询官网进度执行实际只读访问。用户点击已确认投递才写状态、日期及时间线。资料库字段不单独保存版本，完整资料组新版本由显式操作创建。
