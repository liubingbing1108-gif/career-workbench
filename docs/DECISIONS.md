# 当前决定摘要

本页保存通用产品决定；私人对话原文和申请记录不进入仓库。完整规范见 [产品规则](PRODUCT_REQUIREMENTS.md)。

- 独立本机产品；资料和管理两个主入口，岗位工作台为二级页面。
- 管理只收已投及明确要投；候选确认后录入，一行一岗，重复由本人处理。
- 来源链接与核验官网入口分开；公司、具体岗位和官方证据先于登录与填写。
- 已投由本人确认，招聘环节独立，日期人工记录；不自动同步或查询官网进度。
- 永久删除岗位关联记录，保留共享资料、原附件及其他岗位，不撤回官网申请。
- 全表单是主体，简历是来源；字段可空和可扩展，多记录与内容版本分开。
- 教育按网站范围完整取用；实习由本人选择组合、顺序、每段版本；稳定资料复用。
- 增量导入：替换／新版本／忽略。投递编辑：更新／新版本／仅本次，默认仅本次。
- 选定附件直接传原件；允许无新增事实压缩，生成文本须确认，日期不猜日。
- Agent 理解真实问题，程序核验引用，用户在完整预览一次确认后执行。
- 插件自动连接并复用官网现场；未知项先跳过独立部分再集中处理，保护人工修改。
- 上传、保存和回读分别核对；保存后重新打开验证；最终提交由本人完成。
- 私人数据不进源码；新用户可用自己的 Agent，离线和真实验收范围明确。
- 本次先上传私有初步版，排除简历等个人资料；公开与开源许可证后续另行确定。

实现选择可调整，以上语义不能在重构时悄悄改变。新增决定同时更新需求、交接、验收及变更记录。
